# Navo brand assets

Production-ready transparent brand assets for the Navo web app and Figma files.

## Preferred usage

- `navo-wordmark-navy.svg` — light surfaces and expanded navigation.
- `navo-wordmark-white.svg` — navy or dark surfaces.
- `navo-app-icon.svg` — scalable app tile, launcher mark, and compact navigation.
- `favicon.svg` — preferred browser favicon.
- `favicon-32.png` / `favicon-16.png` — raster favicon fallbacks.
- `navo-app-icon-512.png` — high-resolution raster fallback and metadata image.

The PNG files have real alpha transparency. The SVG files use a responsive
`viewBox` and contain no white background rectangle.

## Brand colors

- Navy: `#0B2136`
- Teal: `#2B9E97`
- White: `#FFFFFF`

Do not recreate the wordmark with editable text, apply a drop shadow, or place
the navy wordmark on dark surfaces. Keep the original aspect ratio.
